# AI / ML engineer positioning and job shortlist

Reviewed on 2026-10-07. Assumed search area: France and remote roles compatible with Marseille, based on the existing CV availability. These are accessible employer listings with application links at review time; availability can change. Fit assessments below are inferences from the role descriptions and portfolio, not employer decisions.

## CV positioning

Target AI Engineer, GenAI Engineer and Applied AI Engineer roles first, with ML Engineer roles where software engineering and applied model evaluation are central. Preserve the owner's developer identity: full-stack skills first, then LLM/RAG, databases and DevOps/cloud in the middle, followed by ML/vision and evaluation/monitoring. Emphasize Python, RAG, LangGraph, structured outputs, APIs, evaluation and observability in applications. Support the ML angle with the Zoidberg-AI CNN/VGG16 classification work and the two AI-focused educational programs. Avoid presenting SkillTrail architecture documents as completed model-training results.

Selected professional features supplied by the owner:

- Architecture planner: AI task drafting and rescheduling constrained by dependencies, leave and team capacity through Lucca.
- ROKI knowledge assistant: Azure OpenAI / Azure AI Search RAG, source passages, onboarding checklists and missing/conflicting-information flags.
- Microsoft workflows: extract email requests and dates, prepare document updates and reply drafts for human review.

Personal project examples: Ragbench (retrieval and evaluation), PatchGoblin (bounded CI repair), QueryOtter (PostgreSQL investigation) and Zoidberg-AI (computer vision). No model accuracy, savings or production performance figures were added.
